# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and constructive environment for everyone who participates in this project.

## Expected Behavior

- Be respectful and considerate of others.
- Give constructive feedback and focus on ideas rather than individuals.
- Use inclusive and professional language.
- Respect different backgrounds, experiences, and perspectives.
- Keep discussions relevant to the project.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, hate speech, sexual harassment, deliberate disruption, or other inappropriate conduct are not welcome.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or take other reasonable action when behavior violates this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, please contact the repository owner privately through GitHub rather than posting sensitive details publicly.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other project-related spaces.
