# Contributing

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes and keep them focused.
4. Test the affected functionality locally using the documented setup.
5. Commit with a clear, descriptive message.
6. Open a pull request against `main` and explain what changed.

## Code Quality

- Follow the existing frontend and backend project conventions.
- Keep changes focused and avoid unrelated modifications.
- Take extra care when modifying ordering, payments, wallet, account, or administrative workflows.
- Do not commit secrets, credentials, API keys, `.env` files, payment information, or personal customer data.
- Update documentation when setup, configuration, APIs, or behavior changes.

## Pull Requests

Please include a concise summary, relevant testing performed, and any configuration or migration steps required. Include visual context when a UI change benefits from it.

## Issues

Before opening an issue, check whether a similar issue already exists. For bugs, provide clear reproduction steps, expected behavior, actual behavior, and relevant error information.
